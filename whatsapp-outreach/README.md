# WhatsApp Outreach Copilot (UAE)

Полностью автономный инструмент для полуавтоматической рассылки в WhatsApp через **BitBrowser Local API**.

---

## 🛡️ Безопасность и Лимиты (memory/RULES_WA.md)
* **Профиль 1: WP 1 (Бизнес #1):** лимит **7–8 сообщений в день**, пауза между отправками **15–20 минут**.
* **Профиль 2: wp2 (Номер #2):** лимит **5–6 сообщений в день**, пауза между отправками **20–25 минут**.
* **Анти-спам Spintax:** Каждому контакту генерируется уникальный крючок входа. Нет двух одинаковых цепочек символов.
* **Copilot режим:** Скрипт сам открывает чат, проверяет историю, вбивает хук с опечатками, после чего ждет нажатия **Enter** от человека. После отправки включается аппаратный таймер-замок.
* **Анти-дубль:** Все отправленные номера мгновенно синхронизируются с `data/list.txt`.

---

## 🚀 Быстрый запуск

1. Убедись, что **BitBrowser** запущен на компьютере.
2. Запусти **`1_MENU.bat`** (или `2_SEND_WP1.bat` / `3_SEND_WP2.bat`).

---

## 📥 Импорт контактов (Google Maps / Instant Data Scraper)

1. Выгрузи CSV файл из Instant Data Scraper на Google Maps.
2. В меню выбери пункт `[3]` или выполни:
   ```bash
   python main.py import leads.csv recovery
   ```
3. Фильтр автоматически:
   * Отбросит городские телефоны (`+971 4...`, `04...`).
   * Оставит только мобильные телефоны с WhatsApp (`+971 5...`).
   * Отбросит компании с собственными веб-сайтами.
   * Сверит с `data/list.txt` и исключит дубли.
   * Разобьет номера поровну между WP 1 и wp2.
